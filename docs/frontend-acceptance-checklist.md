# 前端工作台现场验收清单

本文是 `frontend-ui-redesign-plan.md` §16.8 的执行入口。它把可以在本机自动验证的代码门槛与必须在真实 Electron、Provider 和目标设备上采集的证据分开；没有填写现场数据前，不得把“支持大文件/低端设备”写进发布承诺。

## 自动门槛

在仓库根目录运行：

```bash
node tools/measure_stream_transport.mjs --bytes 33554432
node tools/measure_stream_transport.mjs --bytes 33554432 --cancel-after 8388608
node tools/measure_stream_transport.mjs --input /绝对路径/已有文件
```

输出里的 `synthetic=true` 只证明本地有界背压和取消链路可重复，不能替代 Electron IPC、磁盘、网络或 Provider 测试。`--input` 不会修改输入文件，也不会在仓库中生成大样本。

提交前还要通过根目录测试、`electron/npm test`、契约检查和 Electron `--smoke-test`；具体命令与结果记录在重构方案 §16.9。

## 现场证据矩阵

每一行都填写：日期、应用版本/commit、操作系统、设备内存、样本文件 SHA-256、采集日志路径和截图路径。`推断` 不能填入 `实测值` 栏。

| 场景 | 环境/样本 | 必须记录 | G0 阈值 | 当前状态 |
| --- | --- | --- | --- | --- |
| 300MB 文档导入 | 真实可解析 `.docx`，由有效段落生成；8GB SSD 桌面 | Renderer 峰值内存增量、主进程流式缓冲、上传吞吐、取消收敛、同一 source import 重试重复字节 | Renderer ≤64MB、主进程 ≤32MB、吞吐 ≥20MB/s、取消 ≤3s、重复字节 0 | 待现场实测 |
| 300MB 文档导入 | 同一 `.docx`；4GB 低端设备、慢盘 | 同上，另记录 OOM/卡顿与 UI 是否仍可操作 | 峰值增量 ≤96MB | 待现场实测 |
| Excel 词汇 | `examples/documents/U6单词导入模板.xlsx`，覆盖单词、例句、空行和工作表/行号 | 解析条目、`source_locator`、空行处理、错误反馈截图 | 不识别的单元格不得进入可生成条目 | 待现场实测；代码夹具已覆盖投影 |
| 大音频试听 | >16MiB、真实或等价合成 MP3 Artifact | 首帧时间、Renderer 峰值内存、切换条目释放时间、并发媒体/波形数 | 首帧 ≤3s；峰值增量 ≤48MB；释放 ≤2s；媒体 ≤2、波形 ≤1 | 待现场实测 |
| 大 ZIP 下载 | ≥100 个已验证条目的终态任务，限速 ≤5MB/s、慢盘 | 首次进度、写入吞吐、取消收敛、`.part` 清理、重启残留 | 进度 ≤1s、吞吐 ≥2MB/s、取消清理 ≤2s、残留 0 | 待现场实测 |
